# 💰 Money Tracker

Простой и удобный калькулятор для учёта личных средств. Работает прямо в браузере, не требует регистрации, данные хранятся только у тебя.

## ✨ Возможности

- **Три профиля:** личный бюджет, семья, родитель-одиночка
- **Доходы и обязательные расходы** — фиксированные суммы
- **Повседневные расходы** с лимитом на месяц
- **Повседневные доходы** — кэшбэк, возврат долгов и т.п.
- **Переходящий остаток** с прошлого месяца
- **Светофор** — сразу видно, как идут дела с бюджетом
- **Прогресс-бар** по лимиту расходов
- **Автосохранение** — данные не теряются при перезагрузке

## 🚀 Как использовать

Открой сайт: [Hemlock1988.github.io/money-tracker](https://hemlock1988.github.io/money-tracker/)

1. Выбери подходящий профиль
2. Заполни доходы и обязательные расходы
3. Установи лимит на повседневные траты
4. Добавляй операции по ходу месяца
5. Следи за остатком и светофором

## 🔒 Приватность

Все данные хранятся **только в твоём браузере** через `localStorage`. Ничего не отправляется на сервер. Никакой регистрации, никакой рекламы, никакой слежки.
